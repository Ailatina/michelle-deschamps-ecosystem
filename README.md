# Michelle Deschamps · Brand ecosystem

Bilingual ES/EN portfolio and six brand experiences on a shared static codebase.

## Architecture

Plain HTML, CSS and JavaScript. No build service, generation credits, API key, runtime package or paid dependency. A single self-contained index shares brand content, inline SVG masters and one renderer. The brand and lang query parameters select each of the twelve views. The founder photo is served from the existing approved AiLatina asset host.

## Brand roles

- Michelle Deschamps: ecosystem and founder portfolio.
- AiLatina Agents: lead and appointment recovery with human oversight.
- The Audio Healer: music curation and listening experiences, no medical claims.
- Aluma Conscious Stays: conscious spaces and hospitality concepts. Casa Sur remains in development.
- Future-Proof Collective: human collaboration network; the Method/book remains a separate destination.
- One Moment Design: reserved identity, no unverified service offer.

## Contact and privacy

AiLatina inquiries link to the existing application on ailatina.ai. Other collaboration links open the visitor's email application addressed to the existing public business contact. No claim is made that an email has been delivered. This repository does not collect form data, send automatic messages, store leads, charge payments or set analytics cookies. Language has a stable document URL; theme preference may be saved locally.

The existing application was visually inspected, but end-to-end lead persistence, notification delivery and payment processing have NOT been certified by this release. No test records were inserted into production.

## Run

Serve the directory with any static server, for example `python3 -m http.server 8080`, then open index.html. No installation or build step required.

## Asset governance

Six vector identities are normalized v1.0 masters created for this ecosystem, separate from the pre-existing AiLatina corporate identity. Logos are not to be regenerated or altered. Founder image was recovered from the owner's existing AiLatina project. Public brand assets are included; credentials, customer data, account details and private operational documents are excluded.
